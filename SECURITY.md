# Security policy

Report vulnerabilities through [GitHub's private vulnerability form](https://github.com/austin-starks/congressional-disclosures/security/advisories/new). Do not open a public issue for a credential leak, path traversal, unsafe redirect, manifest-integrity bypass, or another exploit that has not been fixed.

Include the affected version, a minimal reproduction, impact, and any conditions required to reach the problem. Remove API keys, session cookies, and private documents.

Security fixes target the current `1.x` release line. Older `0.x` releases receive fixes only when the maintainer says so in the advisory.

Public filing errors and extraction-quality problems are ordinary bug reports unless they also expose or overwrite data outside the requested cache, database, or download directory.
